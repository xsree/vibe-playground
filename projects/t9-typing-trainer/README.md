# 九宫格盲打特训器

用于练习手机九宫格全拼键位与肌肉记忆的纯前端小应用，无需后端、构建工具或外部依赖。

## 本地运行

直接用现代浏览器打开 [index.html](index.html)，也可以通过任意静态文件服务器访问。

## 功能与操作

- 三种训练模式：键位锚点速记、日常高频词连打、60 秒整句挑战。
- 三档盲打遮罩，支持居中、左手与右手键盘布局。
- 实时显示连击、准确率和速度，提供薄弱字母诊断与键位错误率热力图。
- 支持自定义词句，每行格式为 `汉字 全拼字母`，ü 使用 `v`。
- 可触屏点击，也可使用电脑数字键 `1–9`；空格跳过，Backspace 重输，Escape 关闭弹窗。
- 按键音效由 Web Audio API 合成；震动反馈取决于设备与浏览器支持。

错误统计与自定义词句保存在浏览器的 `localStorage` 中。

## 文件结构

- `index.html`：页面结构与入口。
- `styles.css`：布局、键盘、遮罩及弹窗样式。
- `app.js`：内置词库、训练逻辑、交互与本地存储。

从用户提供的 `code_artifact.html` 整理导入，仅拆分内嵌 CSS 和 JavaScript，保留原有界面与训练逻辑。
