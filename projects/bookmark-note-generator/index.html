📒 书签笔记生成器

把一组网址整理成一页笔记，存进一个 data: 书签：离线可以打开，也会跟着浏览器书签同步。本页不联网，可以另存到本地使用。

内容

支持 # 标题、- 列表、1. 有序列表、[文字](链接)、自动识别网址、**粗体**、~~删除线~~、`代码`、> 引用、---、- [ ] 待办，行首缩进两格表示子项。
把浏览器导出的书签 HTML 文件拖到这里，或
  1. Chrome / Edge：书签管理器（Ctrl+Shift+O）→ 右上角 ⋮ →「导出书签」。
  2. Firefox：书签 →「管理书签」→「导入和备份」→「导出书签到 HTML」。
  3. 选中一个文件夹，转换后会切回 Markdown 页，你可以继续给每个网站加备注。
如果笔记带有源文本（「可编辑」模式或勾选了「保留源文本」），可以完整还原；否则只能提取出其中的链接。

📌 拖到书签栏
  1. 新建：把「📌 拖到书签栏」拖到书签栏或书签文件夹里；拖不动就复制地址，然后新建书签，把地址粘贴到「网址」里。
  2. 修改：可编辑笔记可以直接点右下角「编辑」，改完点「保存」（或按 Ctrl+S），会复制新地址；然后右键这个书签 →「修改」→ 用新地址替换网址。
  3. 内容里的 #、% 都会自动编码，不用自己处理。建议每个笔记控制在 64 KB 以内，方便同步。
