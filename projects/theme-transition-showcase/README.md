# 明暗之间 · 主题切换效果试映

在同一个示例界面中直观比较 42 种明暗主题过渡，分为「基础过渡」「空间与纹理」「材质与叙事」「工艺与显像」「物理与空间」五组。双击 [index.html](index.html) 即可运行，无需服务器、安装依赖或构建。

## 使用

- 在左侧选择效果，点击预览右上角的日月按钮或「切换到深色」播放，再次点击可暂停。
- 拖动进度条逐帧观察，点击「重播」重放同一方向；完成后继续切换可查看反方向。
- 调节播放时长（350–1800 ms），在正常速度和慢速之间比较。
- 下方「播放全部」同步播放 42 个预览，也可分别点击每个预览的日月按钮。
- 页头「新增 10 种物理与空间」直接选中焦散游移，第五组包含本轮新增的全部效果；另外两个入口分别选中机械光圈与纸页卷角。
- 「放大试映」将对应效果切换到主预览；「重置浅色」恢复下方全部预览。
- 尊重系统的减少动态效果设置，默认直接完成切换；可手动拖动进度，或主动允许本页播放动画。

## 文件

- `index.html`：页面结构及统一示例界面模板。
- `showcase.css`：响应式布局、明暗配色与按钮图标样式。
- `showcase.js`：独立预览、动画进度采样、同步播放及无障碍交互。
- `authored-effects.js`：8 种材质与叙事效果及其按需创建的 SVG、透镜和字形图层。
- `craft-effects.js`：10 种工艺与显像效果，复用辅助图层的生命周期，包含固定拼片与裂纹几何。
- `physical-effects.js`：10 种物理与空间效果，包含解析光场、分片几何、色光滤镜与星图轨迹。
- `check-effects.cjs`：无需依赖的状态与几何回归检查，运行 `node projects/theme-transition-showcase/check-effects.cjs`（在仓库根目录）。覆盖 42 种效果的双向采样、确定性回拖、暂停、重播、重置、减少动态效果及统一播放；不替代浏览器中的视觉验收。

为支持在同一页独立播放多个效果、手动拖动进度，示例使用普通 DOM 双层画面和 `requestAnimationFrame`，不依赖整页 View Transition API。鹈鹕画廊使用 CSS 颜色过渡实现柔和渐变。所有预览共用相同日月图标，插画由页面内 SVG 构成，无外部素材或网络请求。

颗粒遮罩由页面内 Canvas 生成并共享缓存，水波使用各预览独立的 SVG 滤镜；均无需外部素材。所有效果均支持暂停、进度拖动、双向切换和重播，切换效果或重置时清除临时样式。桌面端主预览随页面滚动保持可见，便于浏览更长的效果列表。

纸页与丝绸以 SVG 曲线、渐变和投影模拟材质；玻璃透镜保留局部放大的独立场景；字形遮罩使用系统中文字体。日蚀、空间和墨色在同一场景中连续改变配色及层次。辅助图层均按需创建、重复使用，在重置时隐藏并清除场景的临时样式。

工艺组继续采用程序化 SVG、CSS 遮罩及同一场景的分层变色。珐琅以固定种子的 Voronoi 分区保证拼片完整覆盖画面；釉裂使用固定分支，进度回拖时不重新随机。光圈在叶片闭合时换场；织纹与光栅在结束时撤去遮罩。浮雕、描边和月相会在重置时清除所有临时投影、描边及天体位移。

物理组为可实时回拖的风格化近似：流体、焦散和薄膜采用确定性的解析光场，并以有界缓存共享栅格结果，不执行完整流体或光线追踪求解。折纸的三角 DOM 分片共享顶点高度，明暗按各面的法线计算；翻带使用参数曲面及四角投影，投影片段共享边界。棱镜以三路 SVG 颜色矩阵分离并合成色光；星图使用选定的场景特征位置与固定弧线，不进行截图或文字轮廓识别。所有辅助场景按需创建、重用，并在重置时隐藏。

需要支持 CSS 遮罩、3D 变换、SVG 滤镜、Canvas 和容器查询单位的现代浏览器。动画只作用于预览区域，展示页自身保持浅色，便于稳定比较。
