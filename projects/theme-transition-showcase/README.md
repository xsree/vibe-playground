# 明暗之间 · 主题切换效果试映

在同一个示例界面中直观比较 9 种明暗主题过渡。双击 [index.html](index.html) 即可运行，无需服务器、安装依赖或构建。

## 使用

- 在左侧选择效果，点击预览右上角的日月按钮或「切换到深色」播放，再次点击可暂停。
- 拖动进度条逐帧观察，点击「重播」重放同一方向；完成后继续切换可查看反方向。
- 调节播放时长（350–1800 ms），在正常速度和慢速之间比较。
- 下方「播放全部」同步播放 9 个预览，也可分别点击每个预览的日月按钮。
- 「放大试映」将对应效果切换到主预览；「重置浅色」恢复下方全部预览。
- 尊重系统的减少动态效果设置，默认直接完成切换；可手动拖动进度，或主动允许本页播放动画。

## 效果

| 效果 | 可观察的区别 |
|---|---|
| 圆形扩散 | 与鹈鹕画廊相同的圆形揭示方式，从右上角按钮向外展开 |
| 柔和渐变 | 对文字、背景、插画的各个颜色分别插值，形状不变 |
| 交叉淡化 | 将完整的新旧画面按透明度叠加 |
| 柔边扫光 | 用有柔边的渐变遮罩扫过，深色向左、浅色向右 |
| 斜向擦除 | 沿清晰的斜线揭示新主题 |
| 帘幕开合 | 从画面中心向两侧展开 |
| 分区错峰 | 页头、内容区、页脚依次改变颜色 |
| 百叶条带 | 9 条横向条带同时展开 |
| 模糊溶解 | 在交叉淡化的同时逐渐虚化、再恢复清晰 |

## 文件

- `index.html`：页面结构及统一示例界面模板。
- `showcase.css`：响应式布局、明暗配色与按钮图标样式。
- `showcase.js`：独立预览、动画进度采样、同步播放及无障碍交互。

为支持在同一页独立播放多个效果、手动拖动进度，示例使用普通 DOM 双层画面和 `requestAnimationFrame`，不依赖整页 View Transition API。圆形扩散演示与现有画廊使用同类视觉方式，未修改原画廊。所有预览共用相同日月图标，插画由页面内 SVG 构成，无外部素材或网络请求。

需要支持 CSS 遮罩和容器查询单位的现代浏览器。动画只作用于预览区域，展示页自身保持浅色，便于稳定比较。
