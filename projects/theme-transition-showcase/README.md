# 明暗之间 · 主题切换效果试映

在同一个示例界面中直观比较 54 种明暗主题过渡，分为「基础过渡」「空间与纹理」「材质与叙事」「工艺与显像」「物理与空间」「工坊与印艺」六组。双击 [index.html](index.html) 即可运行，无需服务器、安装依赖或构建。

## 使用

- 在左侧选择效果，点击预览右上角的日月按钮或「切换到深色」播放，再次点击可暂停。
- 拖动进度条逐帧观察，点击「重播」重放同一方向；完成后继续切换可查看反方向。
- 调节播放时长（350–1800 ms），在正常速度和慢速之间比较。
- 下方「播放全部」同步播放 54 个预览，也可分别点击每个预览的日月按钮；内部启用全局单时钟调度与视口可见性优化。
- 页头「新增 12 种工坊与印艺」直接选中极光帷幕，第六组包含本轮新增的全部传统工坊与现代光学印艺效果；另外三个入口分别选中焦散游移、机械光圈与纸页卷角。
- 「放大试映」将对应效果切换到主预览；「重置浅色」恢复下方全部预览。
- 尊重系统的减少动态效果设置，默认直接完成切换；可手动拖动进度，或主动允许本页播放动画。

## 文件结构

- [index.html](index.html)：页面结构、统一示例界面 `<template>` 与导航入口。
- [showcase.css](showcase.css)：响应式布局、明暗配色、容器查询（`cqw`）与按钮图标样式。
- [showcase.js](showcase.js)：核心时钟调度、全局单 `rAF` 循环（Single Ticker）、视口观察器、独立预览与并排网格。
- [authored-effects.js](authored-effects.js)：8 种材质与叙事效果，提供统一舞台控制器与 O(1) 处理器注册表。
- [craft-effects.js](craft-effects.js)：10 种工艺与显像效果，包含半平面裁剪 Voronoi 拼片与确定性釉裂几何。
- [physical-effects.js](physical-effects.js)：10 种物理与空间效果，包含射影透视变换矩阵、解析光场与三维法线明暗。
- [atelier-effects.js](atelier-effects.js)：12 种工坊与印艺效果，包含黄金螺旋剖分、极光、日晷、拓印与移轴光学。
- [check-effects.cjs](check-effects.cjs)：零依赖的状态与几何回归检查脚本，覆盖 54 种效果的 1404 次双向采样、确定性回拖、暂停、重播、重置、减少动态效果及统一播放。

运行测试命令（在仓库根目录）：
```bash
node projects/theme-transition-showcase/check-effects.cjs
```
