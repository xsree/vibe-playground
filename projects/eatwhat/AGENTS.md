==================================================
产品定义
==================================================

【应用名称】
eatwhat

【真实需求】
我经常不知道一顿饭吃什么。菜谱来自以前看过的做饭视频和记忆。有时不做，是因为忘记步骤、觉得麻烦，或者不方便重新翻视频。

我愿意手动打字整理菜谱。暂不解析 B 站视频，因为涉及内容获取、字幕、语音识别、AI、平台限制与合规。

主要是两个人吃，每次推荐一道菜，不推荐整套餐单。

【产品定位】
一个 Android 手机优先的私人菜谱管理和随机选菜应用。

【第一版功能】
1. 首页随机推荐一道菜。
2. 推荐结果只显示菜名和描述。
3. 提供“查看菜谱”和“换一道”。
4. 查看完整菜谱详情。
5. 浏览全部菜谱。
6. 添加、编辑、删除菜谱。
7. 使用 localStorage 保存。
8. 默认按最近添加排序。
9. 部署成移动网页，核心完成后升级成 PWA。

【不做的功能】
- 图片
- 难度
- 搜索
- 分类
- 排序选项
- 食材库存
- 最近食用历史
- 厨房逐步模式
- AI
- 视频自动解析
- 账号
- 付费
- 社交
- 第一版跨设备同步
- 第一版业务后端

【导航】
底部只有：

- 首页
- 菜谱

添加按钮放在菜谱页面，不单独占底部导航。

主要页面：

1. 首页
2. 菜谱列表
3. 菜谱详情
4. 添加/编辑表单

【路由】
使用原生 URL Hash 路由，方便静态托管和 Android 返回手势：

#/                         首页
#/recipes                  菜谱列表
#/recipes/new              添加菜谱
#/recipes/菜谱ID           菜谱详情
#/recipes/菜谱ID/edit      编辑菜谱

【菜谱字段】
用户输入：

- 菜名：必填
- 描述：选填
- 来源链接：选填
- 食材：必填，每行一种
- 制作方法：必填，每行一步

系统字段：

- id
- createdAt
- updatedAt

提交时去掉首尾空格。缺少必填项时不保存并提示。来源链接填写后必须以 http:// 或 https:// 开头。

【初始示例】
首次打开时预置三道可编辑、可删除的菜谱：

- 番茄炒蛋
- 杏鲍菇炒肉
- 拍黄瓜

只有 localStorage 数据完全不存在时才初始化。用户删除全部菜谱后刷新不能恢复。

==================================================
技术路线
==================================================

【首版】
Vite + 原生 HTML + 原生 CSS + 原生 JavaScript + localStorage

不使用 Tailwind，因为当前目标是补 CSS 基础，且页面数量少。以后 React 重构时再考虑 Tailwind。

【PWA】
移动网页核心完成后，在同一项目上增加：

- manifest.webmanifest
- 应用图标
- display: standalone
- Service Worker
- 离线静态资源缓存
- 添加到主屏幕说明

Android 是主要测试设备。

【后端】
第一版不需要业务后端，只需要 HTTPS 静态托管。

以下功能出现时才考虑后端：

- 账号
- 多设备实时同步
- 多人共享
- 服务端推荐
- AI
- 支付权限
- WebDAV 跨域代理

【未来同步】
未来可能用坚果云 WebDAV 同步 recipes.json。

路线：

1. localStorage
2. JSON 手动导入/导出
3. 尝试坚果云 WebDAV
4. 如果浏览器受 CORS、凭据或冲突限制，再增加小型后端代理

【JSON 备份】
核心完成后实现。

导出：

recipes-backup-日期.json

导入：

- 检查格式；
- 显示文件菜谱数和当前菜谱数；
- 用户确认后完整覆盖当前数据；
- 不自动合并；
- 覆盖前提示先导出当前数据。

【localStorage 格式】

键名：

eatwhat.data

值：

{
  schemaVersion: 1,
  recipes: [
    {
      id: "唯一ID",
      name: "番茄炒蛋",
      description: "酸甜下饭，简单快手",
      sourceUrl: "https://example.com",
      ingredients: [
        "西红柿 2 个",
        "鸡蛋 3 个"
      ],
      steps: [
        "西红柿切块，鸡蛋打散",
        "鸡蛋炒熟后盛出"
      ],
      createdAt: "ISO 时间",
      updatedAt: "ISO 时间"
    }
  ]
}

导出文件增加：

{
  app: "eatwhat",
  schemaVersion: 1,
  exportedAt: "ISO 时间",
  recipes: []
}

规格：

- 页面左右留白 24px；
- eatwhat 24px、粗体；
- 菜名 clamp(40px, 12vw, 56px)；
- 描述 16px，行高 1.6；
- 查看菜谱是红色主按钮，高 54px；
- 换一道是次要文字按钮；
- 底部导航基础高度 64px，加安全区；
- 首次未随机时显示“帮我选一道”按钮；
- 随机结果使用约 180ms 淡入和上移 8px；
- 按钮按下缩放到 0.98；
- 支持 prefers-reduced-motion。
