§ 10.01

Canvas 2D 像素处理：原生矩阵卷积核滤镜实验室

HTML5 Canvas ImageData
PIXEL ALGORITHM & CODE
像素级操作原理： 通过 ctx.getImageData() 获取一维连续 Uint8ClampedArray 像素缓冲区（[R, G, B, A, ...]），直接在客户端进行数学矩阵变换。
JavaScript 
const imgData = ctx.getImageData(0, 0, width, height);
const d = imgData.data;

for (let i = 0; i < d.length; i += 4) {
  const gray = 0.299 * d[i] + 0.587 * d[i+1] + 0.114 * d[i+2];
  d[i] = d[i+1] = d[i+2] = gray;
}
ctx.putImageData(imgData, 0, 0);
§ 10.02

Web Audio API 原生音频振荡合成器与示波器

W3C Web Audio API
点击上方按钮，浏览器将使用纯数学公式合成音频脉冲
AUDIO GRAPH & CODE
音频节点图管线： OscillatorNode (振荡器) $\to$ GainNode (音量衰减) $\to$ AudioContext.destination (扬声器)。无需任何外部音频文件即可合成任意音效。
JavaScript 
const ctx = new AudioContext();
const osc = ctx.createOscillator();
const gain = ctx.createGain();

osc.type = 'sine'; // 正弦波
osc.frequency.value = 440; // A4 音符

osc.connect(gain);
gain.connect(ctx.destination);
osc.start();
