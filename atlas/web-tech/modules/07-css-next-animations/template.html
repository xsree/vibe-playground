SPECIFICATION & CODE
零 JS 动画时间线： 使用 animation-timeline: scroll() 或 view()，浏览器直接将滚动距离映射为关键帧插值，由排版合成器线程直接渲染。
CSS 
/* 纯 CSS 滚动进度条 */
.progress-bar {
  animation: growProgress auto linear;
  animation-timeline: scroll(root);
}

@keyframes growProgress {
  from { width: 0%; }
  to { width: 100%; }
}

SPECIFICATION & CODE
浏览器原生快照过渡： document.startViewTransition() 在改变 DOM 前后分别截取快照，并自动进行伪元素层级补间动画，实现跨视图形态丝滑变形。

// 启用原生平滑视图过渡
document.startViewTransition(() => {
  container.classList.toggle('grid-mode');
});
§ 07.03

CSS 现代级联层 @layer 与作用域 @scope

CSS Cascading & Scope
级联层覆盖测试：

@layer 优先级覆盖测试

即使 @layer base 中写了 ID 选择器（#btn），也一定会被 @layer utilities 中的普通类名覆盖！

SPECIFICATION & CODE
终结特异性混乱： 在 @layer 声明顺序中，后声明的层优先级永远高于先声明的层，层级优先级高于内部任意选择器权重计算。
CSS 
@layer reset, components, utilities;

@layer components {
  .btn { background: #2563eb; }
}

@layer utilities {
  .btn-custom { background: #16a34a; }
}
§ 07.04

下一代色彩空间 OKLCH 与原生混色器 color-mix()

CSS Color Level 4
60%
color-mix(in oklch, blue 60%, white)
SPECIFICATION & CODE
感知均匀色彩空间： oklch() 具备真正的人眼感知亮度线性度，避免了 sRGB / HSL 在黄色和蓝色之间明度突变的缺陷；color-mix() 支持动态生成中间色系。
CSS 
/* 原生色彩混合 */
.tinted-surface {
  background: color-mix(in oklch, var(--primary) 70%, white);
}

/* 宽色域 OKLCH */
.vibrant-blue {
  color: oklch(0.6 0.25 260);
}
