CSS 自动感知子节点变更
SPECIFICATION & CODE
关系伪类规则： :has() 可充当父选择器与前驱兄弟选择器。支持形如 .card:has(input:checked)、h1:has(+ p)。
CSS & Tailwind 
/* 原生 CSS 规则 */
.card:has(#chk-urgent:checked) {
  border-color: var(--accent-warning);
}
.card:has(#chk-danger:checked) .btn {
  background: var(--accent-danger);
}

/* Tailwind 4 语法 */
<div class="has-[:checked]:border-amber-500">
§ 02.02

特异性权重控制 :is() vs :where() 对决

CSS Specificity
:where(.btn) (权重 0) 默认基础样式
:is(.btn) (继承权重) 默认基础样式
SPECIFICATION & CODE
零权重重置： :where() 特异性恒为 0，任何下游单类名（0,1,0）均可轻松覆盖；:is() 则继承参数列表中的最高权重。
CSS 
/* 零权重设计系统重置 */
:where(button, input, select) {
  all: unset;
  border-radius: 4px;
}

SPECIFICATION & CODE
黄金自适应公式： 无需任何 @media 媒体查询，即可让卡片网格根据可用宽度自动折行并填满整行。
CSS 
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 16px;
}

§ 02.06 现代 CSS 选择器与布局规则速查

特性 / 选择器 规范分类 特异性计算 核心能力
:has() Selectors Level 4 由参数中最高权重决定 父级与前驱兄弟选择器，状态双向感知
:where() Selectors Level 4 永远为 0 (0, 0, 0) 基础重置样式库，下游零阻碍覆盖
:is() Selectors Level 4 继承参数列表中最高权重 选择器分组简写，容错解析
@container Container Queries 不改变选择器权重 组件级响应式断点，摆脱全局视口限制
repeat(auto-fit, minmax(...)) CSS Grid Matrix 不涉及 零 @media 查询的响应式流式网格
