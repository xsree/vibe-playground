SPECIFICATION & CODE
Proxy 优势： 可拦截对象新增属性、删除属性及数组下标变更，彻底解决旧时代 Object.defineProperty 的数据监听盲区。
JavaScript 
const state = new Proxy(raw, {
  set(target, prop, val, receiver) {
    const ok = Reflect.set(target, prop, val, receiver);
    triggerUpdate();
    return ok;
  }
});

SPECIFICATION & CODE
零 CPU 滚动损耗： 由浏览器排版引擎在独立线程计算相交面积，避免在主线程监听 scroll 导致页面卡顿。
JavaScript 
const observer = new IntersectionObserver((entries) => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add('visible');
      observer.unobserve(e.target);
    }
  });
}, { threshold: 0.4 });
§ 03.04

异步中止信号 AbortController 与防竞态机制

DOM Standard Abort
Idle
点击上方按钮发起模拟网络请求...
SPECIFICATION & CODE
通用中止信号： 同一个 controller.signal 不仅能中止 fetch()，还能传给事件监听器一键清除。
JavaScript 
let controller = null;

function fetchData() {
  if (controller) controller.abort(); // 丢弃上一次请求
  controller = new AbortController();

  fetch('/api/search', { signal: controller.signal })
    .catch(err => {
      if (err.name === 'AbortError') console.log('已安全中止');
    });
}
