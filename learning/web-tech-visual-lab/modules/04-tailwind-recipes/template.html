§ 04.04 Tailwind 核心修饰符与模式速查

修饰符前缀 底层 CSS 机制 示例用法 典型应用
has-[:checked]:* :has(:checked) 关系伪类 has-[:checked]:border-blue-500 表单选中时父卡片高亮
group-hover:* 父子选择器组合 group-hover:translate-x-1 悬停外部卡片驱动内部图标动效
peer-focus:* 相邻兄弟选择器 (+ / ~) peer-focus:-top-4 浮动标签 Material 风格输入框
w-[calc(...)] 任意值 JIT 编译器 w-[calc(100%-2rem)] 精准像素计算与非预设尺寸覆盖
