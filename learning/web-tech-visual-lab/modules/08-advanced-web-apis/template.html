SPECIFICATION & CODE

};
§ 08.02

流式数据与管道：ReadableStream 打字机渲染

WHATWG Streams
等待流式数据推送...
SPECIFICATION & CODE
流式管道模型： 无需等待整个网络请求载荷完全返回，通过 response.body.getReader() 逐块接收 Uint8Array 并即时解码上屏（大模型流式打字底层原理）。
JavaScript 
const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  renderChunk(decoder.decode(value));
}
§ 08.03

内存泄漏防范：WeakMap 弱引用与自动垃圾回收 (GC)

ECMAScript Memory
目标 DOM 元素节点
已使用 WeakMap 绑定私有元数据。当 DOM 节点被移除且无外部强引用时，GC 会自动回收对应键值对。
SPECIFICATION & CODE
弱引用特性： WeakMap 的键必须是对象，且键对象是弱引用。一旦对象被销毁，垃圾回收器会自动清理对应的映射值，从源头杜绝内存泄漏。
JavaScript 
const privateData = new WeakMap();

// 绑定数据到 DOM 节点
privateData.set(domElement, { metadata: 'safe' });

// 节点被移除时，关联数据自动随之被 GC 回收
§ 08.04

浏览器离线存储方案全景矩阵

Client Storage APIs
各方案存储能力对照：
LocalStorage ~5 MB

同步阻塞、纯字符串键值、跨同源标签页共享

IndexedDB 几百 GB (按磁盘比例)

异步非阻塞、事务型对象存储、支持二进制与复杂索引

OPFS (私有文件系统) 极高 (直通磁盘)

极低延迟同步读写，专为 SQLite WASM 设计

SPECIFICATION & CODE
选型建议： 小型配置读写使用 LocalStorage；结构化数据与离线缓存使用 IndexedDB；高性能数据持久化优先使用 Origin Private File System (OPFS)。
JavaScript 
// 原生 OPFS 私有文件系统读写
const root = await navigator.storage.getDirectory();
const fileHandle = await root.getFileHandle('data.db', { create: true });
const accessHandle = await fileHandle.createSyncAccessHandle();
