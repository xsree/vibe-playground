§ 05.01

Shadow DOM 样式作用域强隔离工作台

DOM Shadow Root
Default Scope
Light DOM (普通 DOM - 无隔离)

组件标题

全局 CSS 样式可直接入侵并修改此区域。

SPECIFICATION & CODE
沙盒隔离机制： attachShadow({ mode: 'open' }) 建立独立的 CSS 作用域。外部全局选择器无法穿透 Shadow Root，内部样式亦不会污染全局宿主。
JavaScript 
const shadow = host.attachShadow({ mode: 'open' });

shadow.innerHTML = `
  <style>
    h4 { color: #38bdf8; font-weight: 600; }
  </style>
  <h4>受保护组件</h4>
`;
§ 05.02

原生自定义元素（Custom Elements）与生命周期

HTML5 Custom Elements
Connected
SPECIFICATION & CODE
命名铁律与生命周期： 自定义标签名必须包含短横线（如 <tech-counter>）。通过 observedAttributes 监听属性变化并自动调用 attributeChangedCallback。
JavaScript 
class TechCounter extends HTMLElement {
  static get observedAttributes() { return ['count']; }
  attributeChangedCallback() { this.render(); }
  render() {
    this.innerHTML = `<span>${this.getAttribute('count')}</span>`;
  }
}
customElements.define('tech-counter', TechCounter);
§ 05.03

模板骨架与具名插槽（Template & Slot）投射

HTML5 Templates
惰性模板克隆
SPECIFICATION & CODE
惰性与性能： <template> 内的图片、视频或脚本在未被 cloneNode(true) 真正插入文档前，浏览器绝不发起网络下载或执行计算。
JavaScript 
const template = document.getElementById('tmpl-profile-card');
const clone = template.content.cloneNode(true);
clone.querySelector('.slot-name-target').textContent = 'Alice';
container.appendChild(clone);
