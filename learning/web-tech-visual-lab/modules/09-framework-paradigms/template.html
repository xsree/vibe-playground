§ 09.01

响应式内核大对决：Signals vs Vue3 Proxy vs React VDOM

Reactivity Core Comparison
Tick: 0
React (VDOM Diff)
组件重执行次数: 0
整树组件函数重新执行，生成新 VDOM 树进行 Diff 调和
Vue 3 (Proxy Track/Trigger)
Effect 触发: 0
属性被修改触发 setter，精准触发订阅该属性的 Render Effect
SolidJS (Fine-Grained Signal)
DOM Text 节点直更: 0
组件函数只执行 1 次！Signal 自动订阅单个 Text 节点直接写入
CORE MECHANISMS & CODE
心智模型差异： React 是“自顶向下的粗粒度重计算”；Vue 是“组件级的依赖收集”；Signals 是“细粒度到单一 DOM 节点的原子订阅”。
JavaScript (Signals 原理) 
// 极简 Signal 核心实现
function createSignal(value) {
  const subscriptions = new Set();
  const read = () => {
    if (currentEffect) subscriptions.add(currentEffect);
    return value;
  };
  const write = (newVal) => {
    value = newVal;
    subscriptions.forEach(fn => fn());
  };
  return [read, write];
}
§ 09.02

跨标签页原生通信：BroadcastChannel API

HTML5 Channel Messaging
BroadcastChannel: lab-sync-channel
> 可以在浏览器另开一个标签页打开本站，在此处发送消息，另一个标签页即可毫秒级同步接收！
SPECIFICATION & CODE
零服务器同源通信： BroadcastChannel 允许同源下的所有浏览器标签页、iframe、Web Worker 之间建立点对多广播通道，无需 WebSocket 后端中转。
JavaScript 
const channel = new BroadcastChannel('app-sync');

// 发送广播
channel.postMessage({ type: 'LOGIN', user: 'Alice' });

// 接收广播
channel.onmessage = (event) => {
  console.log('接收到其他标签页消息:', event.data);
};

§ 09.03 前端响应式机制与通信模型速查

响应式范式 更新触发机制 运行时开销 代表框架
Virtual DOM Diffing State 变更 $\to$ 重执行组件树 $\to$ VDOM Diff 调和 中等（需维护内存中的两棵 VDOM 树） React
Proxy 依赖收集 Getter 收集依赖 (track) $\to$ Setter 派发更新 (trigger) 低（组件级精确更新） Vue 3, MobX
Fine-Grained Signals 原子信号订阅，组件只执行一次，直接更新 Text 节点 极低（零 VDOM，零全树重算） SolidJS, Angular Signals
编译期静态生成 在编译时将赋值语句转换为原生 DOM 修改代码 零额外运行时（Zero Runtime） Svelte
