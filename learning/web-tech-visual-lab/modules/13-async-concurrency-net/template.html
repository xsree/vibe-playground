COMBINATOR SPEC & CODE
allSettled 优势： 永远不会提前 reject，等待所有 Promise 无论 resolve 还是 reject 全部就绪后返回包含 { status, value/reason } 的结果数组，非常适合批量并发埋点与状态上报。
JavaScript 
const results = await Promise.allSettled([
  fetch('/api/user'),
  fetch('/api/posts'),
  fetch('/api/metrics')
]);

results.forEach(res => {
  if (res.status === 'fulfilled') console.log(res.value);
  else console.error(res.reason);
});

PROTOCOL COMPARISON & CODE
SSE (Server-Sent Events) 核心优势： 天然基于标准 HTTP 协议、原生支持断线自动重连、支持消息 ID 追踪。是大语言模型（LLM）对话打字输出与监控通知的绝对最佳技术选型。
JavaScript (EventSource) 
// 原生 SSE 监听
const sse = new EventSource('/api/llm/stream');

sse.onmessage = (event) => {
  renderChunk(event.data);
};

sse.onerror = () => sse.close();

§ 13.03 异步并发 API 与实时协议速查表

API / 协议 通信方向 失败策略 典型适用场景
Promise.allSettled 并发批处理 永不提前 Reject，等待全部结束 多接口批量容错拉取、日志汇总上报
Promise.any 并发竞速 全部失败时抛出 AggregateError 从多个全球镜像 CDN 节点竞速拉取资源
Server-Sent Events (SSE) 服务端 $\to$ 客户端 (单向) 原生浏览器自动断线重连 AI 对话流式打字、股票实时行情、系统通知
WebSocket 客户端 $\leftrightarrow$ 服务端 (全双工) 需自行实现心跳与重连机制 多人在线协同白板、实时多人游戏、即时聊天
