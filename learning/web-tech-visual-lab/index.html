§ 01.01

<dialog> 原生模态对话框与 Top Layer 顶层渲染

HTML5 Top Layer API
6px
点击左上角按钮测试原生模态唤起

原生 <dialog> 模态框

当前元素处于浏览器内核 Top Layer 顶层（高于任意 z-index）。支持按 ESC 退出或按 TAB 测试焦点锁定。
SPECIFICATION & CODE
Top Layer 机制： 使用 showModal() 激活时，浏览器将其移入独立于根 DOM 树的顶层堆叠上下文，自带全屏遮罩，彻底杜绝父容器 overflow: hidden 裁剪问题。
HTML & CSS 
const dialog = document.querySelector('dialog');
dialog.showModal(); // 激活顶层模态

/* 遮罩样式定制 */
dialog::backdrop {
  background: rgba(0, 0, 0, 0.6);
  backdrop-filter: blur(6px);
}

02 / 为什么放弃 JS 手写折叠？ ›
0 运行时代价，完全由浏览器内核驱动渲染，无布局抖动。
SPECIFICATION & CODE
互斥机制： 多个 <details> 标签添加相同 name="group" 属性即可原生实现互斥折叠，无需任何 JS 事件监听。
HTML 
<details name="faq-group" open>
  <summary>标题</summary>
  <p>展开内容</p>
</details>
§ 01.03

表单约束验证 API 与 :user-invalid 防误报校验

Form Constraint API
输入字符并失焦测试校验效果：
SPECIFICATION & CODE
:user-invalid 优势： 区别于传统的 :invalid，:user-invalid 仅在用户产生实际交互并失焦后才触发红框，杜绝页面首屏即全红的缺陷。
CSS 
/* 仅在失焦产生脏数据后高亮错误 */
input:user-invalid {
  border-color: var(--accent-danger);
}

16:9 全景横幅图

SPECIFICATION & CODE
网络层按需拉取： 浏览器在预解析阶段依据视口条件与 AVIF / WebP 格式支持只下载匹配的一张图片，彻底杜绝浪费带宽。
HTML 
<picture>
  <source media="(min-width: 800px)" srcset="banner.avif" type="image/avif">
  <source media="(min-width: 800px)" srcset="banner.jpg">
  <img src="cover-square.jpg" alt="封面" loading="lazy">
</picture>
