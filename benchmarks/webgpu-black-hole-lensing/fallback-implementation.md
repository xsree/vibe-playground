# 高成功率保底实现方法

这份文件只在盲测实现失败后使用。它提供实现路线，不属于盲测 Prompt。

## 推荐技术基线

- 使用 Vite、TypeScript 和 React 构建页面壳层。
- 使用 WebGPU 作为渲染后端。
- 使用 `vgpu` 管理渲染通道、纹理、采样器和离屏目标。
- 使用 `@vgpu/wgsl` 组织可导入的 WGSL 模块。
- 以 vgpu 的 optimized black hole 多通道思路为起点，不要再使用单个片元着色器里直接画同心线条的方案。

## 渲染管线

### 1. 光路烘焙 G-buffer

对每个屏幕像素生成相机射线，在 Schwarzschild 近似下积分测地线。每条射线最多记录两次穿过吸积盘平面的交点：第一次用于正面盘，第二次用于被黑洞弯折后看见的背面盘。

G-buffer 至少保存：

- 第一次穿盘的位置与射线方向。
- 第二次穿盘的位置与射线方向。
- 射线逃逸后的天空方向。
- 观察方向、是否被事件视界吞噬、穿盘次数。

事件视界半径可归一化为 `1`，ISCO 设为约 `3`，相机距离默认约 `13.5`，吸积盘外半径约 `9`。测地线积分应使用半步更新或类似的稳定积分方式，并根据到事件视界的距离动态缩短步长。

相机不动时 G-buffer 不需要每帧重算；相机变化、缩放或画布尺寸变化时才重新烘焙。

### 2. 边缘细化

在事件视界轮廓、穿盘次数发生变化以及光带边界附近进行额外子像素采样。将覆盖率和细化后的几何信息写入独立抗锯齿目标，避免光子环与细光带出现锯齿和闪烁。

### 3. 吸积盘材质

不要用规则线条生成盘面。创建一个可平铺的三维噪声体积纹理，在盘面极坐标中组合多组 fBm、ridge noise 和低频云层：

- 角向频率高于径向频率，形成被轨道运动拉长的气体流。
- 使用半径相关的角速度产生差分旋转。
- 在外缘增加湍流、破碎和不规则边界。
- 使用像素足迹衰减高频八度，防止远处出现摩尔纹。
- 使用光学厚度而不是硬阈值计算透明度。

颜色从外侧暗紫灰过渡到中部浅紫白，再到内侧近白高温区域。叠加引力红移、相对论性多普勒增亮、视线掠射路径长度和内缘能量增益。两次穿盘结果按前后顺序做透明度合成，这一步决定背面光带是否真实存在。

### 4. 星空

根据 G-buffer 中射线逃逸后的方向生成程序化星空。至少使用两档或三档不同尺度的方向哈希，使星点在尺寸、亮度和色温上有变化。被事件视界吞噬的射线不得显示星空。

### 5. HDR 与泛光

盘面与星空先输出到 `rgba16float` HDR 目标。随后执行：

1. 亮部提取。
2. 半分辨率水平、垂直模糊。
3. 四分之一分辨率模糊。
4. 八分之一分辨率模糊。
5. 将三个尺度按近、中、远权重合成。
6. 使用 ACES 或相近曲线做色调映射，再转为显示色域。

泛光强度保持克制，光带中心仍要看得到烟雾和湍流细节。

## 自由轨道相机

- `yaw` 不做钳制，允许无限累计。
- `pitch` 钳制在约 `-1.535` 到 `+1.535` 弧度，也就是约 `±88°`。
- 距离建议限制在 `7.2` 到 `22` 个归一化 Schwarzschild 半径。
- 拖动时使用 pointer capture；水平位移修改 `yaw`，垂直位移修改 `pitch`。
- 滚轮使用指数缩放，使远近移动手感一致。
- 接近极点时仍用安全的正交基生成相机射线，避免叉积退化。
- 相机变化时将 G-buffer 标记为脏；拖动期间可把重新烘焙限制在约每 `40–50 ms` 一次，松手后立即烘焙最终清晰帧。

## 性能与响应式

- 画布输出 DPR 建议固定为 `1`，避免高分屏指数增加光线积分成本。
- G-buffer 最大像素数控制在约 `1.0–1.2` 百万；超出时等比例降低离屏分辨率，最终合成回完整画布。
- 桌面宽屏将黑洞中心放在画面约 `67%` 的横向位置；移动端改为居中。
- 页面隐藏或画布不在视口中时停止动画循环。
- 使用 ResizeObserver 重建离屏目标，旧目标在新绑定完成后再销毁。
- WebGPU 不可用或初始化失败时显示明确错误状态，不要永久显示空白画布。

## 最容易失败的地方

- 只使用一个圆盘网格或二维 SDF：无法正确得到上下背面光带。
- 只记录一次穿盘：会丢失被黑洞弯折后再次看到的盘面。
- 用正弦函数画很多等距纹：会得到难看的分层条带。
- 相机每帧自动旋转：会迫使昂贵的 G-buffer 每帧重算。
- 直接在 LDR 画布上加亮：会造成过曝、发灰和纹理丢失。
- 移动端为了给文字留白而遮罩画布中心：会让前后光带看起来消失。

## 保底验收顺序

1. 先关闭材质和泛光，只检查事件视界、星空弯曲与两次穿盘位置。
2. 再启用纯色吸积盘，确认上下背面光带连续。
3. 加入体积噪声和差分旋转，检查不存在规则分层。
4. 加入 HDR bloom 与色调映射，检查纹理没有被吞没。
5. 最后接入自由相机，并依次测试默认、`±45°`、`±88°`、水平整圈、最近距离和最远距离。
6. 分别用 `1920×1080`、`1366×768`、`390×844` 做截图检查。
